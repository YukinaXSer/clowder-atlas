# Clowder Atlas

用星图浏览笔记的双链关系，查看记忆身份与来源；需要时，将选段交给 Clowder AI 猫猫讨论或修改。

星图、透镜、模板和本地策展可独立使用。对话与选段修改需要另外运行 [Clowder AI](https://github.com/zts212653/clowder-ai)。当前界面以中文为主，命令面板使用英文名称。

## 安装与开始使用

这是首个公开版本，目前尚未在社区插件目录上架。手动安装时，将同一次 Release 的 `main.js`、`manifest.json`、`styles.css` 放入 `<vault>/.obsidian/plugins/clowder-atlas/`，在「设置 → 第三方插件」启用。更新文件后重新加载插件。

本版本只声明支持桌面版 Obsidian **1.14.5+**；这是保守的验收基线，未验证更早版本和移动端。使用插件不需要 Node.js，只有从源码构建时需要 Node.js 22+。

启用后星图和透镜会自动打开。普通笔记也能进入星图；在透镜里点「✨ 赋予这篇笔记记忆身份」，可补充语义/情景/程序等分类。需要自己审阅的内容先存为待结晶笔记，点亮后，位于 `_atlas/pending/` 的笔记才移动到 `_atlas/crystals/`。导出 Canvas 会新建文件。

## 和猫猫一起读

打开「💬 对话」，运行猫咖后点「🔌 一键连接猫咖」，或在「⚙️ 填写地址」中配置。默认 API 地址是 `http://localhost:3004`，连接默认关闭。对话标题行的 ⚙ 可修改地址、刷新伙伴、断开连接。

在笔记编辑视图选中一段，右键点「🐾 把选中段落交给猫猫」，或运行 `Clowder Atlas: Ask Cats About Selection`。直接说「这段逻辑通吗」或「帮我改得更简洁」，不需要先选模式。有选段时只发送选段。猫猫在 `修改稿` 代码块给出完整正文后，可先对照再确认替换。

只有能精确关联到一次选段请求的回复可替换。原文已改、位置不明确或回复归属不清时，只提供复制；后续没附选段的追问也不会自动继承写回目标。在打开的编辑器里替换可撤销；笔记关闭时的文件写入不提供编辑器撤销步骤。同一次请求的多只猫版本可互换。

## 数据与联网说明

本地视图不需要账号或联网；插件没有客户端遥测，不自动下载依赖或执行网络代码。可选猫咖连接会读取所配置 API 的健康状态、成员、对话与消息，并从该实例的前端加载头像。点「一键连接」会探测配置地址和本机的六个常用端口，详见英文 README。

发送消息时，用户指令与附带内容会进入猫咖，并可能转交其配置的模型供应商。普通笔记附带在对话中最多发送前 1,000 字符，研讨会最多 1,500 字符；选段最多 90,000 字符。模型账号、计费和服务端数据保留由猫咖及其供应商决定。

失败原文、附带内容、写回目标和连接配置保存在本地插件的明文 `data.json` 中，失败记录不会按时间或条数自动删除。用户自己的备份或同步也可能包含该文件。详见 [PRIVACY.md](PRIVACY.md)。

## 构建

```sh
npm run build
npm test
```

没有 npm 依赖，不需要先安装包。源码为 `src/main.js`，构建不会改变功能代码，三个安装文件输出到根目录和 `dist/`。`demo/` 只含合成笔记。[发布说明](RELEASE_NOTES.md) · [发布步骤](PUBLISHING.md) · [MIT 许可](LICENSE)。
