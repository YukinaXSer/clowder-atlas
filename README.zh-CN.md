# Clowder Atlas

Clowder Atlas 帮你在 Obsidian 里查清一篇笔记从哪里来、和哪些笔记相连。用透镜查看链接处的原句，点回出处。也可以在 3D 星图上缩放、旋转视角，点一颗星打开对应笔记。

[**观看 71 秒实机演示**](https://yukinaxser.github.io/clowder-atlas/)

[![Clowder Atlas 实机演示封面，显示三只伴读猫和插件名称。](https://yukinaxser.github.io/clowder-atlas/clowder-atlas-demo.jpg)](https://yukinaxser.github.io/clowder-atlas/)

演示录自桌面 Obsidian 上的 Clowder Atlas 0.0.7。片中使用示例笔记和预置猫猫回复，配有中文旁白。

- **查来源。** 透镜顶部显示状态、类型、光泽和来源记录。向下看入链和出链原句，点击卡片跳回出处。
- **收集和整理。** 把几篇笔记中的原句放进同一个引用篮，用模板整理笔记。待结晶笔记由你确认后再点亮，也可把笔记导出到 Canvas。
- **一起读。** 连接正在运行的 Clowder AI 后，可以请猫猫讨论选段、开研讨会，或把回复存为带来源的待结晶笔记。单段修改可先对照再替换。

星图、透镜、模板和笔记整理可离线使用。对话与选段修改需要另外运行 [Clowder AI](https://github.com/zts212653/clowder-ai)。界面以中文为主，命令面板使用英文名称。

## 安装与开始使用

在「设置 → 第三方插件 → 浏览」搜索 **Clowder Atlas**，点击「安装」后「启用」。也可以打开[社区插件介绍页](https://community.obsidian.md/plugins/clowder-atlas)。

手动安装时，将同一次 Release 的 `main.js`、`manifest.json`、`styles.css` 放入 `<vault>/.obsidian/plugins/clowder-atlas/`，在「设置 → 第三方插件」启用。更新文件后重新加载插件。

本版本只声明支持桌面版 Obsidian **1.14.5+**；这是保守的验收基线，未验证更早版本和移动端。使用插件不需要 Node.js，只有从源码构建时需要 Node.js 22+。

启用后星图和透镜会自动打开。要为普通笔记补充分类，可在透镜顶部选择「语义」「情景」或「程序」。确认点亮后，位于 `_atlas/pending/` 的笔记移入 `_atlas/crystals/`。导出 Canvas 会新建文件。

## 和猫猫一起读

打开「对话」，运行猫咖后点「一键连接猫咖」，或在「填写地址」中配置。默认 API 地址是 `http://localhost:3004`，连接默认关闭。对话标题行的「+」可新开一个对话（附着的选段会跟过去），齿轮按钮可修改地址、刷新伙伴、断开连接。

点伴读席的「研讨会」可组织多猫研讨。在「在哪开会」里可选新开对话（默认，先叫「研讨会 · …」，第一只发言的猫猫会按讨论内容给它起名），或用现有对话（默认是对话栏正在看的那个）。

在笔记编辑视图选中一段，右键点「把选中段落交给猫猫」，或运行 `Clowder Atlas: Ask Cats About Selection`。直接说「这段逻辑通吗」或「帮我改得更简洁」，不需要先选模式。有选段时只发送选段。猫猫在 `修改稿` 代码块给出完整正文后，可先对照再确认替换。

只有能精确关联到一次选段请求的回复可替换。原文已改、位置不明确或回复归属不清时，只提供复制；后续没附选段的追问也不会自动继承写回目标。在打开的编辑器里替换可撤销；笔记关闭时的文件写入不提供编辑器撤销步骤。同一次请求的多只猫版本可互换。

## 数据与联网说明

本地视图不需要账号或联网；插件没有客户端遥测，不自动下载依赖或执行网络代码。可选猫咖连接会读取所配置 API 的健康状态、成员、对话与消息，并从该实例的前端加载头像。点「一键连接」会探测配置地址和本机的六个常用端口，详见英文 README。

发送消息时，用户指令与附带内容会进入猫咖，并可能转交其配置的模型供应商。普通笔记附带在对话中最多发送前 1,000 字符，研讨会最多 1,500 字符；选段最多 90,000 字符。在新对话里开研讨会时，会先在猫咖新建这个对话：项目路径是本库路径，临时标题取自附带的笔记名、选段行号或议题开头。模型账号、计费和服务端数据保留由猫咖及其供应商决定。

失败原文、附带内容、写回目标和连接配置保存在本地插件的明文 `data.json` 中，失败记录不会按时间或条数自动删除。用户自己的备份或同步也可能包含该文件。详见 [PRIVACY.md](PRIVACY.md)。

## 构建

```sh
npm run build
npm test
```

没有 npm 依赖，不需要先安装包。源码为 `src/main.js`，构建不会改变功能代码，三个安装文件输出到根目录和 `dist/`。`demo/` 只含合成笔记。[发布说明](RELEASE_NOTES.md) · [发布步骤](PUBLISHING.md) · [MIT 许可](LICENSE)。

## 跨文件多选段交叉研讨（0.0.6）

在笔记里选中文字，右键「把选中段落交给猫猫」，再到另一篇笔记重复操作，选段会依次累加为 #1、#2……同篇不同段也可收集；相同位置与文字不会重复加入。点击来源胶囊返回原笔记，点移除按钮单独移除，或清空引用篮。未发送选段随插件数据持久保存，不自动过期。选段总量最多 90,000 字符，最终正文加提问、来源标签也须在猫咖消息上限内。

输入「对比 #1 与 #2」直接发送，或打开「研讨会」使用交叉比对、证据链、综合提炼、正反辩论预设。「+」新对话会保留整篮选段；有选段时不夹带整篇笔记。

多选段综合修改稿仅提供复制，单选段继续支持对照后替换。存为待结晶笔记时，根据回复所回答的那次请求关联全部源笔记，并使用库内完整路径区分同名文件；不会混入同一对话其他批次或当前打开的无关笔记。猫咖未提供输入消息归属时，不推断多源关系。发送失败后可重发原消息或将全部选段放回输入框。
