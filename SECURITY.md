# Security

Do not include real note contents, API credentials, or an unredacted `data.json` in a public issue. Provide a synthetic reproduction, the plugin and Obsidian versions, and the affected feature.

For a vulnerability, use private reporting through this repository's Security tab if enabled. Otherwise contact the maintainer through their GitHub profile before disclosing sensitive details. An ordinary issue is appropriate for a non-sensitive bug.

The optional Cat Cafe connection can transmit attached note material. Its current client follows the local `default-user` convention. This release candidate does not claim an authentication boundary for an arbitrary remote or multi-tenant service.
