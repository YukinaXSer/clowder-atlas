# Clowder Atlas demonstration

Every note in this folder is synthetic and intended for a disposable test vault.

Enable Clowder Atlas to open the star chart and the Provenance Lens. Open a note and inspect its memory type and status. The pending example can be crystallized from the Lens; it moves to the crystals folder. Create an empty Markdown note to try adding a memory identity. Export Atlas notes to create a Canvas.

The chat panel starts offline. It can explain how to connect a separately running Cat Cafe. This demo does not contain connection settings, failed messages, or a real conversation.
